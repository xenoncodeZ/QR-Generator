# QR Generator

A simple Python application that generates QR codes from text or URLs and saves them as an image.

## Features

- Generate QR codes from any text
- Supports website URLs
- Saves QR codes as PNG images
- Easy to use
- Beginner-friendly project

## Technologies Used

- Python
- qrcode
- Pillow

## Installation

Clone the repository:

```bash
git clone https://github.com/xenoncodeZ/QR-Generator.git
```

Go to the project directory:

```bash
cd QR-Generator
```

Install the required package:

```bash
pip install -r requirements.txt
```

## Usage

Run the program:

```bash
python main.py
```

Enter the text or URL when prompted.

The generated QR code will be saved as a PNG image.
